title: "Pulumi Any Terraform"
description: "TypeScript Pulumi packages bridged from Terraform providers."
---

These packages are published for TypeScript. Each npm package is named `pulumi-` plus the provider name.

<Visibility for="agents">
Resource pages are `/pulumi-any-terraform/providers/<provider>/resources/<resource>`. Function pages are under `functions`. Nested object fields are under that object heading. A long reference continues on the linked part pages. They are not arguments of the parent. Use only properties listed on the page.
</Visibility>
