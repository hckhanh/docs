A `slack` destination needs `slackWorkspaceId` and `slackChannelId`; `webhook` and `teams` need `webhookUrl`. Any other value is sent to PostHog as given, so a destination type added to the API works without a new provider release. Terraform cannot check the settings a type it does not know requires, so PostHog reports those at apply.                                                                                                                                                                           |
| `webhookUrl`       | `string` | no       | URL to POST the notification to. Required when `type` is `webhook` or `teams`. For `teams`, this is the Microsoft Teams incoming webhook URL. Marked sensitive because the secret is in the URL: whoever holds it can post to the channel. PostHog redacts the URL when reading destinations, so Terraform keeps the configured value and never compares it against the live one. A destination's URL cannot change in place: PostHog has no update endpoint for one, and the Hog Function API refuses writes to alert-owned destinations. Changing a URL outside Terraform means deleting the destination and adding another, which changes `hogFunctionIds` and does show up as drift. Rotate the URL by changing it here. |
