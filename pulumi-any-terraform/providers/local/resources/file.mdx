| --------------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `content`             | `string` | no       | Content to store in the file, expected to be a UTF-8 encoded string. Conflicts with `sensitiveContent`, `contentBase64` and `source`. | `contentBase64`       | `string` | no       | Content to store in the file, expected to be binary encoded as base64 string. Conflicts with `content`, `sensitiveContent` and `source`. Default value is `"0777"`.                                                                                                                         |
| `filename`            | `string` | yes      | The path to the file that will be created. Missing parent directories will be created. If the file already exists, it will be overridden with the given content.                                                                                                                                                             |
| `sensitiveContent`    | `string` | no       | Sensitive content to store in the file, expected to be an UTF-8 encoded string. Will not be displayed in diffs. | `source`              | `string` | no       | Path to file to use as source for the one we are creating. Conflicts with `content`, `sensitiveContent` and `contentBase64`.
